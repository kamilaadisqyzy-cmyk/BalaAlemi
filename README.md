# «Балдәуреннің цифрлық әлемі»

Тәрбиешінің цифрлық шығармашылық кеңістігі: мектепке дейінгі балаларға арналған авторлық ойындар, бейнелер, әндер және ата-аналармен жұмыс материалдары.

## Құрамы

- `index.html` — сайттың өзі: 8 бөлім, материал парақтары, іздеу мен сүзгі.
- `games.html` — интерактивті ойындар (нағыз 3D ойындар мен шығармашылық ойындар), мектеп жасындағы балаларға арналған.
- `audio/` — «Әуенді әлем» бөлімінің 10 әні.
- `video/` — «Көр де, үйрен!» бөлімінің 8 бейнесі.
- `img/`, `eko/` — суреттер, ойын суреттері және 3D кітапхана (three.js).

## GitHub Pages арқылы ашу

1. Репозиторийде **Settings → Pages** бөліміне өтіңіз.
2. **Source**: «Deploy from a branch», **Branch**: `main`, папка: `/ (root)` — **Save**.
3. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://kamilaadisqyzy-cmyk.github.io/BalaAlemi/`

GitHub Pages-те Delightex Edu сахнасы («Орман және үй жануарлары») материал бетінің ішінде ашылады.
